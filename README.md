# 卖家利润助手 · 本地优先 Web 应用

第一版是可静态托管的浏览器应用：没有登录、后端 API、自建服务器、云端数据库、自动同步或 AI 金额生成。订单、明细、退款、平台费用、成本、其他费用、结算、导入批次、校验行、异常和计算结果保存在当前网站来源下的 IndexedDB。`localStorage` 只保存当前页面、店铺筛选和日期范围等少量偏好。

## 本地运行

需要 Python 3（只用于提供静态文件）和现代浏览器。PowerShell 从项目根目录运行：

```powershell
python -m http.server 8766 --bind 127.0.0.1 --directory static-app
```

打开 <http://127.0.0.1:8766>。这个命令只提供 HTML、CSS、JavaScript 和随附的 Excel 解析库，不接收导入文件，也不运行应用后端。也可将 `static-app/` 的内容发布到任何支持 HTTPS 的静态托管平台。

## 数据位置与隐私

- 数据保存在当前设备、当前浏览器、当前网站来源的 IndexedDB。关闭页面、重启浏览器或刷新后会自动读取同一份数据库。
- 换设备、换浏览器、换网站域名/端口不会自动同步。浏览器清理站点数据、隐私模式结束或设备故障也可能删除数据；请定期下载 JSON 备份。
- 导入解析、字段映射、校验、清洗、计算、图表和 Excel 导出均在浏览器本地完成。静态托管收到的只是页面资源请求；应用没有文件上传接口、云数据库或 AI 服务调用。
- 源文件只在内存中解析，不保存原始文件二进制。为便于追溯，映射后的来源行值和字段校验结果会存入当前浏览器的 IndexedDB，并会包含在 JSON 备份中。
- 设置页显示本机浏览器存储估算，并可请求持久存储。浏览器可能拒绝该申请；无论结果如何，都应另存备份。

## 快速体验

首次打开后点“载入虚构演示数据”。样例包含 12 笔虚构订单、商品成本、退款、费用与结算，可查看趋势、商品对比和利润估算。使用导入页选择店铺及报表类型，检查自动字段映射和错误/重复/冲突行，再手动确认写入。淘宝/天猫、拼多多、抖音等字段映射目前是通用表头建议，未使用真实脱敏平台报表验证，不能视为已验证兼容。

已支持 CSV、TSV、XLS、XLSX、XLSM；读取 Excel 文件的第一个工作表。单文件上限 20 MB、最多 50,000 行。订单号、SKU、数量、日期、金额和状态需按报表类型通过校验。重复文件会阻止再次导入；相同业务键会跳过，内容不同则作为冲突保留给人工检查。

## 计算规则

货币转换为整数分后累计，数量按千分之一件存储。已知项目利润估算为：有效订单商品实付 − 统计期内已确认退款 − 已匹配商品成本 − 已导入平台费用 − 已导入其他费用。订单按下单日计入，退款按退款完成日计入，所以跨月退款出现在退款完成月份。取消订单不计入销售，未知状态单独提示。缺少成本时，系统不会把未知成本当成已知零成本，而会标记估算不完整。结算差异只是简化复核信号，不等于平台最终对账。

## 备份、恢复和清空

在“备份与设置”下载 JSON 文件并妥善保管。恢复会先校验备份，再通过两次确认整体替换当前 IndexedDB；替换在一个数据库事务内完成，失败时旧数据会回滚。清空也必须通过两次确认，无法撤销。请在恢复前另存当前数据备份。

## 测试

逻辑测试（Node.js 18+）：

```powershell
node --test static-app/tests/domain.test.mjs
```

端到端浏览器测试需要 Node.js 22+、Python 3，以及 Edge 或 Chrome。测试脚本自动创建临时浏览器配置、启动本地静态文件服务器、导入 CSV/XLSX、验证解析错误和重复保护、导出 Excel、操作备份/恢复/清空，并关闭后重开浏览器检查 IndexedDB。默认查找 Edge 安装路径；也可通过 `EDGE_PATH` 指定浏览器可执行文件：

```powershell
node static-app/tests/browser-persistence-smoke.mjs
```

旧的 Flask/SQLite 原型文件仍保留在项目根目录，但不属于此静态版，也不会随 Render 静态配置部署。其历史说明见 [DEPLOYMENT_GUIDE.md](DEPLOYMENT_GUIDE.md)；第一版静态应用以本 README 和 `render.yaml` 为准。

## 目录

```text
static-app/
├── index.html
├── styles.css
├── js/                  # 页面、IndexedDB、导入、计算、备份和导出逻辑
├── tests/               # 逻辑及浏览器端到端测试
└── vendor/              # 随站点本地提供的 SheetJS CE 和许可
render.yaml              # Render 静态站点 Blueprint
```

Excel 读取/生成使用随站点提供的 SheetJS Community Edition 0.20.3，许可信息见 [THIRD_PARTY_NOTICES.md](static-app/THIRD_PARTY_NOTICES.md)。
